Описание

Проект с автотестами для учебного сервиса «Яндекс.Самокат» (qa-scooter.praktikum-services.ru).  
Покрыты все ключевые пользовательские сценарии: заказ самоката, работа FAQ и переходы по логотипам.

## Структура проекта

Sprint_6/
│
├── page_objects/
│   ├── home_page.py              # Page Object главной страницы
│   ├── home_page_locators.py     # Локаторы главной страницы
│   ├── order_page.py             # Page Object страницы заказа
│   ├── order_page_locators.py    # Локаторы страницы заказа
│
├── tests/
│   ├── test_faq.py               # Тесты FAQ 
│   ├── test_logo_click.py        # Тесты переходов по логотипам «Самокат» и «Яндекс»
│   ├── test_order.py             # Тесты заказа 

│
├── conftest.py                   # Фикстуры Pytest
├── requirements.txt              # Список зависимостей проекта
└── README.md

-- Описание файлов и папок

- page_objects/ — Page Object классы и локаторы, инкапсулируют логику и элементы сайта
- tests/ — автотесты на функционал сервиса:
    - test_order.py — позитивные сценарии заказа самоката с разными наборами данных и обеими кнопками заказа
    - test_faq.py — тесты FAQ, каждый вопрос проверяется отдельным тестом
    - test_logos.py — тесты переходов по клику на логотипы «Самокат» и «Яндекс»
- conftest.py — общая настройка и фикстуры для тестовой среды (Selenium WebDriver)
- requirements.txt — зависимости для запуска тестов
