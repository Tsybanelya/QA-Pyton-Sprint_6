QA Automation Project: Тестирование сервиса "Самокат"
Описание проекта
Этот проект представляет собой автоматизированные тесты для сервиса аренды самокатов. Проект включает тесты для проверки функциональности главной страницы, страницы заказа и навигации по логотипам.
Структура проекта
project/
+---data_test                 # Тестовые данные
|   |   data.py
|   |   __init__.py
├── pages/
│   ├── base_page.py          # Базовый класс для всех страниц
│   ├── home_page.py          # Страница главной страницы
│   └── order_page.py         # Страница оформления заказа
├── locators/
│   ├── home_page_locators.py # Локаторы для главной страницы
│   └── order_page_locators.py # Локаторы для страницы заказа
├── tests/
│   ├── test_faq.py           # Тесты для FAQ
│   ├── test_logo_click.py    # Тесты навигации по логотипам
│   └── test_order_page.py    # Тесты оформления заказа
├── conftest.py               # Фикстуры pytest
└── requirements.txt          # Зависимости проекта
Тестовые сценарии
1. Тесты FAQ (test_faq.py)
•	Проверка корректности ответов на вопросы
•	Проверка сворачивания ответов при повторном клике
2. Тесты навигации (test_logo_click.py)
•	Проверка перехода на главную страницу по логотипу Самоката
•	Проверка перехода на Дзен по логотипу Яндекса
3. Тесты оформления заказа (test_order_page.py)
•	Позитивные сценарии оформления заказа
•	Тестирование через обе кнопки "Заказать" (верхняя и нижняя)
•	Проверка различных комбинаций данных
Тестовые данные находятся в файле data.py и включают:
•	Данные для оформления заказа (2 набора)
•	Вопросы и ответы для FAQ
•	URL-адреса
Используемые технологии
•	Python 
•	Selenium WebDriver - для автоматизации браузера
•	Pytest - фреймворк для тестирования
•	Allure - для генерации отчетов
•	Firefox - браузер для тестирования
Локаторы
Проект использует паттерн Page Object Model с отдельными файлами локаторов:
•	HomePageLocators - локаторы главной страницы
•	OrderPageLocators - локаторы страницы заказа
Особенности реализации
•	Ожидание элементов с помощью WebDriverWait
•	Обработка исключений и таймаутов
•	Поддержка разных браузеров (настроено для Firefox)
•	Параметризованные тесты для покрытия разных сценариев
Требования к окружению
•	Python 3.7 или выше
•	Firefox браузер
•	Geckodriver (должен быть в PATH)
